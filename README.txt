FOOTBALL PREDICTOR V1.0

Archivos:
- app.py: interfaz de la aplicación
- football_prediction_engine_v1(1).py: motor de predicción original
- matches_demo(1).csv: datos de demostración
- requirements.txt: dependencias

Para ejecutarla en un ordenador con Python:
1. pip install -r requirements.txt
2. streamlit run app.py
